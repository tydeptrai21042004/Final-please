## Real DTD status

The failed DTD result was generated by the earlier implementation, which froze both task heads. The corrected implementation has not been rerun on DTD in this CPU-only environment. Therefore, controlled tests support the correction, but a DTD test-set improvement is not claimed until the included Kaggle runner executes the real benchmark. Test labels are never used for selection.
